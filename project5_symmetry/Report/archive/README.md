# Archive — superseded paper lineage

Kept for provenance only. Nothing here is built or cited by the current paper.

The current paper lives in `../elife/` (`main_best.tex`, the source of truth) and
`../biorxiv/` (ported from it). Build with `compile_report.sh` at the repo root.

- `r.tex` -- the original single-file report, superseded by `../elife/main_best.tex`.
- `r_fixed.tex` -- a later revision of `r.tex`; the version the old `compile_report.sh` built.
- `r_original_backup.tex`, `r.tex.backup` -- point-in-time backups of `r.tex`.
- `r.pdf`, `r_fixed.pdf` -- last renders of the above.
- `drafts/` -- earlier drafts (`r_draft{1,2,3}.tex`) and the critique notes written against them.
- `figures/` -- the figure set the `r.tex` lineage used. The current papers use their own
  `../elife/figures/` and `../biorxiv/figures/`, regenerated by `analysis/make_paper_figures.py`.
- `stats_results_srsa.csv` -- a loose sRSA comparison table (S1/S2/S4), unreferenced by any
  paper version. Was sitting at the `Report/` root as `stats_results (3).csv`.

Note: `../images/` was NOT archived. It looks legacy, but `../slides/talk.tex` still pulls
`fig_arenas_overview.png` from it.
